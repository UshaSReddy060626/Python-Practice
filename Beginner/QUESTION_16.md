## Question

What is the output of the following code?

```python
x = "Hello"

print(len(x))
```

## Options

**A.**

```text
4
```

**B.**

```text
5
```

**C.**

```text
6
```

**D.**

```text
It raises an error.
```

---

## Answer

**Correct Option:** B

### Explanation

The `len()` function returns the number of characters in a string.

The string

```python
"Hello"
```

contains:

- H
- e
- l
- l
- o

which is a total of **5** characters.

Therefore,

```python
len("Hello")
```

returns:

```text
5
```
