## Question

What is the output of the following code?

```python
x = "Python"

print(x[0])
print(x[-1])
```

## Options

**A.**

```text
P
n
```

**B.**

```text
P
o
```

**C.**

```text
n
P
```

**D.**

```text
y
n
```

---

## Answer

**Correct Option:** A

### Explanation

Python strings support indexing.

The first character has index:

```text
0
```

So:

```python
x[0]
```

returns:

```text
P
```

Negative indexing starts from the end of the string.

The index:

```text
-1
```

refers to the last character.

Therefore:

```python
x[-1]
```

returns:

```text
n
```

The output is:

```text
P
n
```
